Filecraft guide

System requirements.

No account or cloud conversion dependency. Some workflows need optional local software.

Desktop

Supported release architectures are Windows x64, Linux x64 and macOS ARM64/x64. Qualification evidence names the CI hosts; it is not a promise of every historical OS version. Keep the extracted runtime together. Use a local filesystem with hard-link support for exclusive output publication.

Optional engines: Tesseract for OCR; FFmpeg for media. They are not bundled or downloaded automatically. Desktop inputs/outputs are bounded at 100 MiB, with tighter page/render/parser limits.

Browser

JavaScript and Web Workers required. Files stay in memory while the workspace is open. Reloading loses unsaved work. Large documents may exceed device limits even within the published input bounds.
