Filecraft / Field guide

Start with the requirement.

Three useful paths—not a hundred disconnected tools.

01

Prepare a PDF for an application

Set the actual portal limits yourself. Import PDFs, order the pages, create a copy, inspect the checks and open the saved file in a PDF reader. Never assume a named institution is certified.

02

Create a reusable preparation rule

Load a personal JSON profile for recurring work. Keep the same mechanical requirements across the browser and desktop, while respecting each adapter’s supported formats.

03

Check a copy after the handoff

Keep a receipt separately. Select it and a later copy to compare SHA-256 and byte count. A mismatch means different bytes; a match does not establish authorship or safety.
