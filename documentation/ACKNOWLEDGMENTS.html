Prepare / Documentation

Acknowledgments and project conventions

Prepare uses Apple system frameworks and no third-party application packages. Its page/check artwork and website are original project assets.

Repository conventions were informed by inspecting established projects:

  • LocalSend contributing guide: practical local build instructions, tests, private security reporting and contributor responsibility. Prepare has its own AI-assistance policy.
  • HandBrake contributing guide: focused contribution routing and explicit project scope.
  • ShareX repository: separate security policy, workflow automation and clear release-oriented project organization.

These are organizational inspirations, not code dependencies or endorsements. No source code or documentation text was copied from them.
