LOCAL DOCUMENT READINESS

Accessibility

Keyboard and clear state are product requirements.

Available affordances

Semantic web headings and labels, visible focus, keyboard-operable page controls, drag alternatives, live status text and reduced-motion support. Documentation supports browser text zoom and a system light/dark theme.

Known limits

No WCAG conformance certification is claimed. Stable image-converter raster PDFs are not tagged accessible documents and contain no searchable OCR text. Desktop OCR can add searchable text, but does not create tagged accessible PDFs or certify reading order. Visual source/PDF review cannot replace an accessible text equivalent. Native screen-reader and physical mobile testing remains incomplete.

Report a barrier

Use the issue tracker with platform, browser or screen reader, the control involved and expected behavior. Do not attach confidential documents.
