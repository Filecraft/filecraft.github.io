Filecraft guide

Accessibility.

Semantic pages, visible focus, keyboard controls, reduced motion and explicit unknown states.

What is tested

Responsive overflow, keyboard skip links, labeled inputs, light/dark modes and no-JavaScript navigation are automated checks. The PDF workspace exposes reordering as labeled buttons rather than drag-only controls.

What is not claimed

No blanket WCAG certification or complete screen-reader qualification. A prepared PDF is not automatically accessible. Desktop screen-reader behavior depends on OS/Tk and needs broader user testing. Report a reproducible barrier through support.
