Filecraft / Field guide

Useful defenses.
Honest limits.

Filecraft is not a sanitizer, malware scanner, full parser sandbox or authenticity service.

Threat boundaries

Input limits, private staging, exclusive output publication and subprocess boundaries reduce specific risks. Native parsers still process untrusted bytes. Browser workers improve responsiveness, not universal containment. Avoid hostile files and keep your OS, browser and optional engines updated.

Encryption protects a PDF according to the selected operation; it does not secure all temporary storage. Rewriting can invalidate signatures or lose features. Review the output.
