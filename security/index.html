LOCAL DOCUMENT READINESS

Security

Document inputs are untrusted.

Report privately

Open a private vulnerability report. Include version, platform, reproduction and a minimal synthetic sample. Never put an exploit with sensitive documents in a public issue. No guaranteed response window is promised.

Boundaries

Inputs, dimensions, byte budgets and page counts are bounded. Conversions are cancellable between codec operations. Platform image/PDF libraries still parse hostile bytes: checks are not a substitute for patched operating systems. Android native stream failures are latched to reject truncated PDFs.

PDF parser

The PDF beta bundles a local MIT-licensed pdf-lib adapter. Browser jobs use disposable workers with a 30-second deadline; this is not a hard memory cap. File/page limits cannot rule out malicious compressed resources. Use trusted documents. Active or interactive inputs are rejected conservatively; the tool is not a sanitizer.

Current limits

Mac is ad-hoc signed and not notarized or sandboxed. Android is unsigned experimental. Portable depends on the security of the browser and extensions. No external security audit, malware-proof parser, secure deletion or complete sandbox is claimed.
