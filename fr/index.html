Comprendre le traitement local ↗

Avant de commencer.

Est-ce gratuit ?

Oui. Filecraft est gratuit. Le code original actuel est sous Apache-2.0. Les dépendances et anciennes versions conservent leurs licences.

Peut-il respecter toutes les limites de taille ?

Non. Certains fichiers ne peuvent pas être assez réduits sans perte. Vérifiez toujours le résultat et les règles du destinataire.

Quelle version choisir ?

Le navigateur permet de gérer les pages PDF. L’app gère aussi les images et la conversion de documents centrée sur le texte. L’OCR et les médias nécessitent des outils locaux supplémentaires.

Pourquoi une alerte de sécurité ?

La bêta Windows n’est pas signée et l’app Mac n’est pas notariée. Respectez les règles de votre organisation et gardez les protections actives. Vous pouvez utiliser le navigateur.
