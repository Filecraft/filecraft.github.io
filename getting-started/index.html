Filecraft / Field guide

Your first prepared copy.

No account. No onboarding wizard. Start with the file and the actual requirement.

Browser or extension

  1. Open the workspace. Try the synthetic sample first if useful.
  2. Choose your PDFs and set actual byte/page limits.
  3. Order, remove or rotate pages. Undo/redo stays local to the open session.
  4. Create the copy and read every failed or unknown check.
  5. Save a new file and optional receipt. Open the saved PDF in a reader and inspect every page.

Desktop

  1. Choose a qualified beta package and extract the entire folder.
  2. Open the app; select a file and an offered output format.
  3. Set personal requirements if applicable. Choose a new destination.
  4. Review output and save the optional receipt.

For OCR/media, install the optional local engine yourself. Requirements and limitations →
