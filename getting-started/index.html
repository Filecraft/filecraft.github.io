Getting started

Prepare a separate copy. Review before you submit.

Using Desktop suite?

Extract the full desktop ZIP, launch Prepare-Desktop, choose a local file and select an output format. Adjust options, export to a new filename, then preview the output. PDF passwords are passed locally, not uploaded. See the format and prerequisite guide. Unavailable conversions are not offered. Unsupported files still support ZIP/GZ archival wrapping.

Starting with an existing PDF?

Use the separate PDF Workbench beta. Add ordinary PDFs, arrange the numbered source pages, set the size ceiling and create a copy. To extract a subset, remove unwanted pages; to merge, add more source files. Reopen the saved file in a trusted PDF reader and review every page. Import resets history; closing the tab discards it. For image scans, use the converter instructions below.

1. Install or open

Mac: extract the ZIP and open Prepare.app. It is not notarized; use your normal organization-approved app policy. Never disable Gatekeeper globally. Portable: extract all files and open index.html, not a page still inside the ZIP. Android: follow the developer signing instructions in its source directory.

2. Set the requirement

Read the destination’s current rules. Choose a decimal MB limit, page size, margins and compression profile. Generic presets are examples, not verified institution requirements.

3. Add and arrange

Use local synthetic or non-sensitive images while learning. Add up to 20 supported images. Sort, move, rotate or remove pages using buttons; drag is never required.

4. Prepare and check

Review every output page, including faint stamps, signatures and small text. If the quality floor cannot meet the cap, reduce pages or raise the limit. A failed operation must not offer a successful result.

5. Save a new file

Use a local, unsynced destination and a new name. Mac enforces exclusive export; browser downloads and Android providers have their own overwrite behavior. Check the final file in an independent reader.
