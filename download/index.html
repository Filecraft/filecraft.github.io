Before opening

Verify the checksum first, then follow the install steps for your platform: open the DMG and drag Filecraft to Applications, run the Windows setup, or install the Ubuntu package with sudo apt install. Portable archives must be extracted whole. Desktop binaries are unsigned/not notarized. Do not bypass operating-system protections.
