Prepare / Field guide

Privacy is a boundary,
not a badge.

No document uploads, accounts, analytics or telemetry in Prepare’s processing workflow.

Local processing

Desktop conversion is local. The extension has no host permissions and its CSP forbids network connections. The web workspace processes explicitly selected files locally. Optional engines execute on your device.

What can still reach a network

GitHub serves this website, source and downloads and has its own logging/privacy practices. Browser/OS updates and third-party optional tools have separate behavior. Cloud-backed file pickers and synced save locations can upload outside Prepare’s control. Choose local, non-synced storage.

Receipts and support

Receipts expose hashes, sizes and personal requirements; browser receipts may include filenames. They are optional and saved locally. Do not post private documents, passwords or sensitive receipt data in public issues. There is no telemetry opt-out because no telemetry is built in.
