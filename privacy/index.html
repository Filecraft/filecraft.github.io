LOCAL DOCUMENT READINESS

Privacy policy

Document processing stays on your device.

Applications

I’m Goni Sulaiman, the independent maintainer. I do not operate a document upload service, account system or analytics endpoint for these apps. Released converters process documents locally. Portable blocks connections with Content Security Policy; Android requests no network permission. The Mac release is not sandboxed, so this is not a claim of OS-enforced network isolation.

Local data

Selected originals remain unchanged by conversion. Workspaces, generated versions, temporary data, browser downloads, OS swap and backups can contain sensitive information. Closing or deleting a file is not guaranteed forensic erasure. Use local storage and device encryption appropriate to your needs.

Third parties

This website, source and downloads are hosted by GitHub, which receives normal web requests and may log IP addresses. Opening documentation or update links is networking. System file pickers may expose cloud providers; selecting them can involve their services even though the engine itself never uploads documents. Browser extensions have separate access policies.

Support

Public issues are public. Do not attach identity documents, secrets or real confidential samples. For vulnerabilities use the private reporting link on the Security page. There is no automatic diagnostic upload.
