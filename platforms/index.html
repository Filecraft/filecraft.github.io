Filecraft / Field guide

Cross-platform.
Not identical-platform.

A clear distinction between tested native packages, browser workflows and experiments.

01

Desktop

Native Python/Tk suite builds for Windows x64, Linux x64, macOS Apple Silicon and Intel. Builds must pass platform CI and frozen-worker tests before release. Unsigned/not notarized; no claim for every OS version.

02

Web

A local-processing PDF workspace and retained portable image tool. A website running on a phone is not an iOS app.

03

Browser extension

MV3 Chromium/Edge package and Firefox adapter. Installed-extension workflows tested locally. Store listings are not published. Safari is blocked by missing converter/signing/distribution prerequisites.

04

Mobile

Native mobile development is retired. Historical Android experiments remain only in the archive; no iOS or iPadOS native application is published.
