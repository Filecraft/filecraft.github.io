Platforms

One product direction. Explicit support boundaries.

Available

Native macOS on Apple Silicon; Portable in existing Windows/Linux/macOS desktop browsers; unsigned Android engineering artifact.

PDF beta

Existing Windows/Linux/macOS desktop browsers and Node 22+ share the same PDF page adapter. No native Windows/Linux app or mobile PDF support is implied.

Architecture

Platform image codecs and save dialogs remain adapters. Shared readiness rules and declarative model workflows run independently of UI in the 0.6 beta. Portable and the source CLI consume the same module. Shipping 0.5 converters retain their existing implementations; full unification is not claimed.

Not yet distributed

Windows x64/ARM64 native hosts, Linux packages, native Intel Mac, iOS/iPadOS and additional platforms need their own build, install and device qualification. No compatibility follows merely from source portability.
