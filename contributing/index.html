Contributing

Build a tested vertical slice.

Clone the repository and read CONTRIBUTING.md and the platform README before editing. Native Mac uses Swift and Apple frameworks. Portable runtime is dependency-free JavaScript; Playwright is test-only. Android uses Java and pinned SDK tools with no runtime libraries.

Add a failing regression, implement the smallest coherent fix and verify real output. Bound memory, preserve originals, use synthetic fixtures and record platform limitations. Do not add uploads, telemetry, invented success reports or unreviewed cryptography.

Contributions retain the project’s Hippocratic License 3.0 core. Do not submit code whose license or ownership is incompatible.
