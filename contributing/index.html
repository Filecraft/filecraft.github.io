Filecraft / Field guide

Show the failing case.

Contributions should improve a user workflow and include evidence.

A practical contribution

  1. Describe the requirement or failure, not just a proposed feature.
  2. Create a synthetic fixture and regression test.
  3. Preserve originals, limits and honest unknown states.
  4. Run relevant tests and document adapter/platform limits.
  5. Preserve third-party notices and identify copied code.

New contributions to project-owned code are under Apache-2.0. No assumption is made that vendor code can be relicensed.
