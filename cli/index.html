Filecraft guide

Use Filecraft from the command line.

Automate supported preparation and byte verification without a GUI.

Desktop CLI

Filecraft-Desktop formats input.png
Filecraft-Desktop prepare input.png --target pdf \
  --output prepared.pdf --max-bytes 2000000
Filecraft-Desktop prepare input.png --target pdf \
  --output another-copy.pdf --profile requirements.json
Filecraft-Desktop verify prepared.pdf --receipt receipt.json

The preparation response contains the receipt object; save that object as JSON to verify later. Source invocation: python desktop/launch.py followed by the same arguments, with desktop requirements installed. Errors use exit 1; a fingerprint mismatch uses exit 2.

No accidental overwrites

Use a fresh destination. Failed mechanical requirements block publication; unknown checks remain unknown. Interruptions may leave a copy completed immediately before cancellation.
