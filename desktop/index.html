Filecraft / Field guide

The broader local workbench.

For documents, images and PDF work that needs installed engines.

Prepare without losing the original

The suite snapshots input for processing, stages a new output and refuses to replace an existing destination. Work runs in a separate cancellable process. PDF previews identify their source; local Tesseract and FFmpeg are optional, separately installed engines.

The 0.9 workspace generation adds requirement gates before publication, receipts and a CLI over the same worker. These are beta workflows, not a sandbox guarantee.

Desktop downloads

Installation boundaries

Extract the complete directory; do not move just the executable. macOS binaries are not notarized. Windows binaries are unsigned. Organizational policies may prevent execution. Do not disable operating-system security to run Filecraft.
