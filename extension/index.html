Prepare / Field guide

The preparation tab
beside your application tab.

A real local PDF workspace. No access to the page you are visiting.

Deliberately narrow permissions

No host permissions, content scripts, upload interception, native messaging or remote code. Clicking the extension opens its own workspace. You choose local PDFs explicitly; the extension cannot read arbitrary downloads or form fields.

Source preview; not yet publicly packaged

The extension is locally built and tested, but a public package is not available yet. Build from the development source and its instructions. Chromium and Edge use unpacked developer mode. Firefox uses temporary add-on installation in about:debugging, removed on browser restart. Neither is a store publication or a normal permanent Firefox install.

Chrome Web Store, Edge Add-ons and AMO need authenticated owner access and applicable developer agreements/review. Safari additionally needs Apple tooling, signing and distribution qualification. No store listing is claimed.
