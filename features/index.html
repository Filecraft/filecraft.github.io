Filecraft guide

What you can do.

Work with PDF pages, images and documents on your own device.

01

Requirements

Set a file-size limit, page count or image dimension. Save the rules as a profile for next time. Check which rules your chosen version supports.

02

PDF preparation

Browser: merge, reorder, remove, rotate and extract pages, with undo/redo. Desktop: previews, optimize, rasterize, encrypt/decrypt, fill and annotate.

03

Broader local preparation

Desktop image conversion, text-first document conversion, optional Tesseract OCR and FFmpeg media conversion. Arbitrary files can be ZIP/GZ packaged; not universally converted.

04

Verification receipts

Save a receipt to check whether a copy changes later. The desktop app stops exports that fail your rules. The browser asks you to review the copy before saving it.
