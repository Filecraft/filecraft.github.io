LOCAL DOCUMENT READINESS

Features

A document is ready only when the evidence says so.

Desktop suite 0.8 beta

Native desktop format dropdowns, source/output PDF preview, broad image conversion, text-first document extraction, PDF encryption/decryption, basic form filling and notes. Optional local OCR and FFmpeg media conversion. Lossless ZIP/GZ works with arbitrary file extensions, but no all-format semantic conversion is claimed.

New in the 0.7 PDF beta

Real PDF merge, extraction, reordered and duplicated pages, clockwise rotation, reversible browser history and an exclusive-output CLI. The same locally bundled adapter runs in browser workers and Node. Outputs are parsed again and page geometry checked. Full PDF conformance and visual fidelity remain unverified.

Readiness foundation

Shared tri-state readiness, offline JSON requirement profiles and reversible page operations with undo/redo. A separate source CLI inspects headers and hashes files; its workflows edit a model, not a PDF.

Try the beta · Engine architecture

Working in stable converters

Convert JPEG/PNG images into ordered size-constrained raster PDFs. Reorder, rotate, duplicate and remove pages. Set compression, paper and margins. Preserve original files.

Platform-specific strengths

Mac: HEIC, PDFKit review and true grayscale PDF streams. Portable: spread splitting, arbitrary DPI ceiling and optional near-white cleanup. Android experimental: native image selection, layout, serial decode and verified save-copy bytes.

Not claimed

Stable converters accept images. The separate PDF beta handles ordinary pages, but does not edit text, run OCR, fill forms, encrypt output or certify PDF/A. Readability requires human review; a byte limit alone is not proof of submission acceptance.
