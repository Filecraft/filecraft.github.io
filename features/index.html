Filecraft / Field guide

Evidence, not guesswork.

Choose a workflow by the result you need. Each surface has explicit boundaries.

01

Requirements

Personal byte, page, format, dimension, orientation and filename profiles. Desktop and browser adapters share a declarative schema; format support differs.

02

PDF preparation

Browser: merge, reorder, remove, rotate and extract pages, with undo/redo. Desktop: previews, optimize, rasterize, encrypt/decrypt, fill and annotate.

03

Broader local preparation

Desktop image conversion, text-first document conversion, optional Tesseract OCR and FFmpeg media conversion. Arbitrary files can be ZIP/GZ packaged—not universally converted.

04

Verification receipts

New workspace generation records output bytes and a hash. Desktop gates failed requirements before publication. Browser requires acknowledgment of manual review before download.
