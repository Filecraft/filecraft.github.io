Filecraft guide

Save your file requirements.

Save a file-size or page limit as a profile and use it again next time.

Example: a personal PDF ceiling

{
  "version": 1,
  "id": "my-application",
  "constraints": {
    "formats": ["pdf"],
    "bytes": {"max": 2000000},
    "pageCount": {"min": 1, "max": 5}
  }
}

This is an example, not an official portal profile. Two million bytes means decimal 2 MB. Verify current requirements at the destination.

Supported rule vocabulary

Byte ranges, page counts, PNG/JPEG/PDF formats, dimensions in px or pt, orientation and filename rules. Units must match observed evidence. No executable actions, network sources or institutional certification are embedded.
