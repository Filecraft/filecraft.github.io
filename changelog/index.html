What changed.

New behavior is versioned; historical release claims stay historical.

0.10: Filecraft

The project is now Filecraft. This release adds desktop PDF auto-fit, keeps original files intact, and moves the official site to filecraft.github.io.

0.9 workspace generation

Personal requirement gates on desktop output, shared-worker CLI, hash-bound receipts and saved-copy verification. Local PDF extension adapters. Rebuilt product site and workspace identity. Prospective Apache-2.0 licensing with third-party notices preserved.

0.8 and earlier

0.8 introduced the broader desktop suite. 0.7 added browser/Node PDF workflows. Stable 0.5 image tools and experimental Android remain downloadable with their original scope.
