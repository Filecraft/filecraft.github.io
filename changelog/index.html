Changelog

Versioned changes, not future claims.

0.7.0-beta.1

Real local PDF page operations in a desktop-browser workbench and Node CLI, bounded worker execution, output reparse/geometry checks, richer readiness explanations and updated pinned CI action runtimes. Stable native releases remain unchanged.

0.6.0-beta.1

Shared readiness engine, reversible Portable history, offline profiles, source CLI and light/dark workbench. Native Mac and Android releases remain at 0.5.0.

0.5.0

Native DPI ceilings and identity-safe page actions. Portable custom DPI, per-page controls and optional near-white normalization. An independent Android experimental release adds native image preparation with tested exact-byte failure handling.

0.4.0

Compression profiles, presets, batch controls and a native review workbench.
